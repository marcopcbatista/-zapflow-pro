# 🚀 ZapFlow Pro

Plataforma SaaS de Automação para WhatsApp

## 📦 Instalação

```bash
npm install
```

## 🔧 Desenvolvimento

```bash
npm run dev
```

## 🚀 Build

```bash
npm run build
```

## 🌐 Deploy

```bash
vercel --prod
```

## 📝 Configuração

1. Configure suas credenciais do Supabase em src/App.jsx
2. Configure seu link de pagamento
3. Execute npm run dev para testar
4. Execute vercel --prod para deploy
